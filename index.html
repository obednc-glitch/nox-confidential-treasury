Nox Confidential Treasury

Client-side encryption and decryption for a confidential Safe treasury module. Amounts never leave your device unencrypted.

How execution works: this page only handles encryption and decryption — the actual on-chain transaction (calling fund() or requestPayout()) is executed through your Safe's own interface at app.safe.global, using the encrypted values generated here. This keeps multisig execution on Safe's audited infrastructure rather than reimplementing it.
